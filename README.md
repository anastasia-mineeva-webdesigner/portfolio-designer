# Mira Smirnova — portfolio

React 19, TypeScript, Vite, обычный CSS. Макет и UI Kit:
https://www.figma.com/design/cq0Wj2JTCIpmrrPO2zVTuY/?node-id=354-8683

## Текущая версия

Hero использует новый пользовательский ролик `generation_QYPP8_1iERK.mp4`: локальная копия — `public/media/hero-current.mp4` (1920×1080, 24 fps, 4.04 с). Добавлены короткий GOP и faststart для скраббинга; содержание ролика сохранено. При открытии — нулевой кадр, начало прокрутки сразу изменяет время видео, обратный скролл возвращает предыдущую позу. Дополнительного ожидания закрепления сцены нет. H1 находится над медиа-областью. About остаётся отдельным белым статичным блоком с фото из Figma.

Tool Icon восстановлены из исходного компонента UI Kit **307:2325**: вернули исходные плитки и цвета знаков без изменения их оформления. В коде используются полные SVG-экспорты пяти компонентов, в Figma восстановлены 40 экземпляров Hero из их исходных компонентов. Положения метрик сохранены: две пары по бокам на 1440/1920, два столбика на 1200 и планшетах, сетка под изображением на mobile. Портрет/ролик desktop прижат к нижней границе Hero.

Рисованные подчёркивания шапки используют **только зелёный #c6ff34**, в том числе при focus-visible. Сохраняются перекатывание Primary-кнопок, odometer, след курсора и одинаковое посимвольное проявление Experience/Process. Reduced motion показывает постер вместо видео и отключает движение.

## Запуск и проверки

Node.js 22.12+:

```sh
npm ci
npm run dev
npm test
npm run build
```

Production-файлы находятся в `dist/`; сборка рассчитана на корень домена. Проверки: TypeScript/Vite, математика и геометрия (12 тестов), декодирование видео, сверка Tool Icon с UI Kit. Текущая визуальная проверка HTML в браузере не выполнена: в среде Sites отсутствует `cua_repl.js`. История — `docs/verification.md`.

## Настройки

- `src/config/media.ts` — активное видео и постер Hero, отдельное фото About.
- `src/components/HeroVideo.tsx` — связь прокрутки со временем, обработка загрузки/ошибок/reduced motion.
- `src/config/animation.ts` — `underline.color` (зелёный), тайминги и включение остальных эффектов.
- `src/config/hero-layout.mjs`, `src/components/HeroMetrics.tsx` — восемь схем и группы метрик.
- `src/responsive.css`, `src/tokens.css` — адаптивы и отступы.
- `src/config/links.ts` — контакты, проекты и PDF; неизвестные ссылки обозначены `null`.

## Публикация и прежнее монтажное демо

Основной сайт: https://mira-portfolio-preview.swoonywallaby64.chatgpt.site/

Существующий Sites-проект указан в `.openai/hosting.json`. После GitHub push исходники синхронизируются в репозиторий Sites; затем сохраняется и публикуется версия. Доступ остаётся публичным.

Прежнее отдельное демо из двух фотографий сохранено по `?demo=motion` на desktop от 1200 px. Оно не подменяет новый пользовательский ролик на основной странице. Это монтаж с dissolve, без нейрогенерации промежуточных поз.

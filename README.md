# Mira Smirnova — portfolio

React 19, TypeScript, Vite, обычный CSS. Макет и UI Kit:
https://www.figma.com/design/cq0Wj2JTCIpmrrPO2zVTuY/?node-id=354-8683

## Текущая версия

Hero и About объединены в одну закреплённую сцену с одним пользовательским видео `generation_QYPP8_1iERK.mp4` (`public/media/hero-current.mp4`, 1920×1080 / 24 fps / 4.04 с). В основной сцене нет второй статичной фотографии.

Прокрутка растянута на **4.5 высоты окна на desktop/tablet** и **4.2 на mobile**. На старте ролик стоит на нулевом кадре. В начале скролла исчезают H1, метрики, инструменты и стикеры; то же видео плавно перемещается вверх и уменьшается, под ним поднимается About с описанием, тегами и кнопкой. Видео заканчивается на 72% пути, About полностью появляется на 86%; оставшийся участок оставляет время на чтение. Обратная прокрутка возвращает предыдущую стадию без накопления анимаций.

Высота закреплённой области рассчитывается по окну и фактической высоте текста: для небольших экранов сохраняется место под текст, вместо обрезки содержимого. Reduced motion превращает сцену в обычные последовательные блоки с постером, текстом и доступной кнопкой. Якорь About ведёт к готовой стадии второй части.

Tool Icon взяты из исходного UI Kit **307:2325**, с оригинальными плитками и цветами знаков. Дудлы навигации — только зелёные #c6ff34. Перекатывание кнопок, odometer, след курсора и одинаковое проявление Experience/Process сохранены.

## Запуск и проверки

Node.js 22.12+:

```sh
npm ci
npm run dev
npm test
npm run build
```

Production-файлы находятся в `dist/`; сборка рассчитана на корень домена. Проверки: TypeScript/Vite, математика и геометрия (15 тестов), декодирование видео, сверка Tool Icon с UI Kit. Текущая визуальная проверка HTML в браузере не выполнена: в среде Sites отсутствует `cua_repl.js`. История — `docs/verification.md`.

## Настройки

- `src/config/media.ts` — активное видео и постер Hero/About; старое фото не рендерится.
- `src/components/HeroVideo.tsx` — время общего видеослоя, загрузка/ошибки/reduced motion.
- `src/config/intro-scene.mjs` (доступно также через `animation.introScene`) — длина прокрутки, диапазоны ухода Hero, подъёма видео, появления About и перемещения текста.
- `src/components/VideoScene.tsx` — единый контроллер и измерение геометрии закреплённой сцены.
- `src/config/animation.ts` — `underline.color` (зелёный), тайминги и включение остальных эффектов.
- `src/config/hero-layout.mjs`, `src/components/HeroMetrics.tsx` — восемь схем и группы метрик.
- `src/responsive.css`, `src/tokens.css` — адаптивы и отступы.
- `src/config/links.ts` — контакты, проекты и PDF; неизвестные ссылки обозначены `null`.

## Публикация и прежнее монтажное демо

Основной сайт: https://mira-portfolio-preview.swoonywallaby64.chatgpt.site/

Существующий Sites-проект указан в `.openai/hosting.json`. После GitHub push исходники синхронизируются в репозиторий Sites; затем сохраняется и публикуется версия. Доступ остаётся публичным.

Прежнее отдельное демо из двух фотографий сохранено по `?demo=motion` на desktop от 1200 px. Оно не подменяет новый пользовательский ролик на основной странице. Это монтаж с dissolve, без нейрогенерации промежуточных поз.

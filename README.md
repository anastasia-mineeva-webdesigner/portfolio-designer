# Mira Smirnova — portfolio

React 19, TypeScript, Vite, обычный CSS. Макет и UI Kit:
https://www.figma.com/design/cq0Wj2JTCIpmrrPO2zVTuY/?node-id=354-8683

## Текущее состояние

Hero и About — статичные светлые секции в обычном потоке. Скролл не закрепляет первый экран, не скрывает его и не запускает видео. Hero использует исходное прозрачное фото `/assets/poster.png`, About — отдельное фото из Figma `/assets/about-static.png`. На desktop/tablet H1 состоит из двух строк, на телефоне — из четырёх, как в мобильном макете. Фото находится под заголовком.

Пять инструментов экспортированы из Figma отдельными SVG-знаками, без окружающих плиток. Светлые знаки получили тёмную заливку для светлого фона. У UI Design / AI Agents / 3D & Motion убрана заливка внутренней подложки по прямому указанию пользователя; остальная векторная графика сохранена.

Работают рисованные подчёркивания навигации, перекатывание букв Primary-кнопок, odometer, след курсора и проявление текста. Крупный текст Process использует тот же посимвольный scroll-эффект, что Experience; прежнее быстрое проявление всего абзаца заменено. Настройки Experience сохранены. Reduced motion показывает текст и числа сразу.

## Запуск и проверки

Node.js 22.12+:

```sh
npm ci
npm run dev
npm test
npm run build
```

Production-файлы находятся в `dist/`. Сборка рассчитана на корень домена.

`npm test` проверяет математику скролла и геометрию восьми вариантов Hero. Полная браузерная проверка текущего рендера не выполнена: в среде Sites отсутствует `cua_repl.js`. История проверок — `docs/verification.md`.

## Настройки

- `src/config/animation.ts` — эффекты, цвета, тайминги, auto/on/off; `textHighlight` общий для Experience и Process.
- `src/config/media.ts` — текущие статичные фотографии; `videoSrc` пустой.
- `src/config/hero-layout.mjs` — восемь схем Hero и `staticHeroLayout` для двухстрочного desktop/tablet H1.
- `src/responsive.css`, `src/tokens.css` — адаптивы, отступы и цвета.
- `src/config/links.ts` — ссылки на контакты, проекты и PDF. Недостающие адреса обозначены `null`.

Цвет и толщину следа можно менять во время работы:

```js
document.documentElement.style.setProperty('--cursor-trail-color', '#111111');
document.documentElement.style.setProperty('--cursor-trail-width', '3px');
```

## Следующая итерация видео

Для будущего ролика нужны версии 16:9 и 9:16 со светлым фоном и свободным местом сверху под H1; девушка должна располагаться ниже текста. Механику запуска/скролла нужно проверить с финальными файлами перед повторным включением.

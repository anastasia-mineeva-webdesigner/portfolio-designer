# Mira Smirnova — portfolio

Адаптивное портфолио по странице «Макет в разработку» и UI Kit:
https://www.figma.com/design/cq0Wj2JTCIpmrrPO2zVTuY/?node-id=354-8682

React 19, TypeScript, Vite. Стили — обычный CSS, без Tailwind. Шрифты и изображения хранятся локально.

## Запуск

Node.js 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Проверки и production-сборка:

```sh
npm test
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Для публикации под каталогом настройте `base` в Vite и абсолютные пути к ресурсам; текущая версия рассчитана на корень домена.

## Где подключить видео

1. Поместите файл в `public/media/hero.mp4`.
2. В `src/config/media.ts` замените `videoSrc: ''` на `videoSrc: '/media/hero.mp4'`.
3. Если нужно, замените `poster` кадром начала видео.
4. Проверьте кадрирование на всех ширинах и настройте `objectPosition` в `src/config/animation.ts`.

Используется один видеослой для Hero и About. Фото из About отдельно не подключено. До готовности видео используется постер Hero. Видео не проигрывается автоматически: положение скролла задаёт время, пауза скролла оставляет соответствующий кадр. Обновление ждёт метаданные/готовность и завершение предыдущего seek. При ошибке остаётся постер. Подключён временный ролик `public/media/hero-test.mp4` (854×480, 24 fps, 4.04 с), подготовленный из generation_qY7rg.mp4. Для скраббинга добавлены ключевые кадры каждые 6 кадров и faststart. Постер взят из первого кадра, его геометрия совпадает с видео. Один ролик используется на всех ширинах с центральным cover-кадрированием; финальные 16:9 и 9:16 ещё ожидаются.

Для плавного скраббинга экспортируйте MP4/H.264 с частыми ключевыми кадрами и `faststart`. Подберите битрейт и разрешение под мобильную загрузку. `preload="auto"` — подсказка браузеру, а не гарантия полной загрузки.

## Настройки

- `src/config/animation.ts` — все темпы и переключатели анимаций, отдельные настройки desktop/mobile.
- `src/config/media.ts` — видео и постер.
- `src/config/links.ts` — Telegram, социальные сети, email, PDF резюме, шесть ссылок на проекты.
- `src/tokens.css` — типографика, цвета, поля, межколонники и отступы.
- `src/components/UI.tsx` — Button (Primary, Secondary, Navigation), Label, Tag, Decoration.

Ссылки, которых не было в исходных материалах, обозначены `null`: нажатие показывает уведомление, не ведёт на выдуманный профиль. Email в подвале сохранён из макета (`hello@example.com`) как временный текст. Перед публикацией замените его и заполните реальные адреса. PDF резюме ещё не предоставлен.

FAQ показывает все ответы сразу, как в актуальном компоненте Figma. Hover — белая подложка. Кнопки и ссылки имеют видимый клавиатурный фокус. Мобильное меню закрывается по Escape и при выборе якоря. В reduced-motion видеосцена превращается в обычные последовательные блоки с доступным контентом.

## Проверка

`npm test` проверяет обратный скролл, скачки прогресса, крайние значения и замену видео другой длительности. `npm run build` проверяет TypeScript и production-сборку. GitHub Actions запускает оба шага.

Макеты изучены для 1920, 1440, 1200, 1024, 768, 414, 390 и 360 px. Пять дополнительных эффектов проверены в Chromium на этих восьми ширинах, с эмуляцией touch и reduced motion (см. `docs/verification.md`). Чек-лист для ручной проверки — `docs/verification.md`. Не считать автоматическую сборку подтверждением попиксельного соответствия.

## Анимации по референсам

Все настройки находятся в `src/config/animation.ts`:

- `underline`: `mode: 'auto' | 'on' | 'off'`, desktopMin (1200 px), drawMs/fadeMs, color, width, offsetPx. Шесть случайных SVG-линий без повтора подряд; auto требует desktop + hover/fine pointer. В on доступны мобильные пункты меню и нажатия без задержки перехода.
- `textHighlight`: крупный H3 в Experience; enabled, from/to (цвета в формате `#rrggbb`), startViewport/endViewport, reversible, feather. По умолчанию белый → чёрный, 80% → 40% окна; для длинного блока диапазон не короче его высоты. Переносы происходят между словами, цвет букв связан со скроллом без временной интерполяции.
- `buttonRoll`: enabled, durationMs, staggerMs, maxTotalMs. Все текущие Primary-кнопки; иконки неподвижны. Для длинной надписи stagger уменьшается, чтобы уложиться в maxTotalMs. Повторный вход во время цикла не ставится в очередь.
- `odometer`: enabled, heroMs, experienceMs, staggerMs, turns. Четыре метрики Hero и числа 7 / 2024 в H3 Experience. После готовности шрифтов и видимости 50%, один раз. Единицы и плюс не двигаются; промежуточные цифры скрыты от скринридера.
- `cursorTrail`: mode, lifetimeMs, maxPoints, color, width. Один Canvas с ограничением DPR до 2 и RAF только пока есть точки. В auto требует мышь; on разрешает мышь на любой ширине. Сенсорные жесты не рисуют след.

Значения cursorTrail.color/width задают начальные CSS-переменные. Их можно менять во время работы:

```js
document.documentElement.style.setProperty('--cursor-trail-color', '#111111');
document.documentElement.style.setProperty('--cursor-trail-width', '3px');
```

Reduced motion имеет приоритет над on: текст и числа сразу в конечном состоянии, перекатывание, подчёркивания и Canvas выключены. Обработчики, observers и незавершённые анимации очищаются при размонтировании. Дополнительные зависимости не установлены.

## Сверка адаптивов и тестовое видео

`src/config/hero-layout.mjs` хранит геометрию Hero и About для восьми ширин Figma. Области H1, видео/инструментов и показателей отделены: видео располагается под H1, а до цифр оставлено не менее 24 px. На коротком окне высокий первый экран сначала прокручивается до конца, затем закрепляется для скраббинга. По мере перехода к About размеры сцены и положение общего видеослоя меняются к координатам About. Reduced motion сохраняет статические блоки.

`src/responsive.css` содержит сверенные отступы, межколонники, размеры декоративных элементов, мобильный футер и CTA. Hero/About используют `media.background` в `src/config/media.ts` — нейтральный цвет, взятый из тестового видео. Остальные секции белые; лаймовый CTA, чёрный футер и фоны меток оставлены по Figma. SVG-стикеры UI Design/AI Agents прозрачны вокруг рисунков.

Новая сверка выполнена по структуре и коду Figma для 1920, 1440, 1200, 1024, 768, 414, 390 и 360 px. В среде Sites отсутствует `cua_repl.js`, поэтому актуальное попиксельное совпадение в браузере и отсутствие всех визуальных пересечений не подтверждены. `npm test` дополнительно проверяет границы медиа/иконок и показателей на всех восьми схемах, переходы breakpoint и прогресс высокой закрепляемой сцены.

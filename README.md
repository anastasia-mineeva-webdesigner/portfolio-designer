# Mira Smirnova — portfolio

Адаптивное портфолио по странице «Макет в разработку» и UI Kit:
https://www.figma.com/design/cq0Wj2JTCIpmrrPO2zVTuY/?node-id=354-8682

React 19, TypeScript, Vite. Стили — обычный CSS, без Tailwind. Шрифты и изображения хранятся локально.

## Запуск

Node.js 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Проверки и production-сборка:

```sh
npm test
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Для публикации под каталогом настройте `base` в Vite и абсолютные пути к ресурсам; текущая версия рассчитана на корень домена.

## Где подключить видео

1. Поместите файл в `public/media/hero.mp4`.
2. В `src/config/media.ts` замените `videoSrc: ''` на `videoSrc: '/media/hero.mp4'`.
3. Если нужно, замените `poster` кадром начала видео.
4. Проверьте кадрирование на всех ширинах и настройте `objectPosition` в `src/config/animation.ts`.

Используется один видеослой для Hero и About. Фото из About отдельно не подключено. До готовности видео используется постер Hero. Видео не проигрывается автоматически: положение скролла задаёт время, пауза скролла оставляет соответствующий кадр. Обновление ждёт метаданные/готовность и завершение предыдущего seek. При ошибке остаётся постер. Готовое видео пока не предоставлено: реальную плавность декодирования и положение персонажа нужно проверить с финальным файлом.

Для плавного скраббинга экспортируйте MP4/H.264 с частыми ключевыми кадрами и `faststart`. Подберите битрейт и разрешение под мобильную загрузку. `preload="auto"` — подсказка браузеру, а не гарантия полной загрузки.

## Настройки

- `src/config/animation.ts` — все темпы и переключатели анимаций, отдельные настройки desktop/mobile.
- `src/config/media.ts` — видео и постер.
- `src/config/links.ts` — Telegram, социальные сети, email, PDF резюме, шесть ссылок на проекты.
- `src/tokens.css` — типографика, цвета, поля, межколонники и отступы.
- `src/components/UI.tsx` — Button (Primary, Secondary, Navigation), Label, Tag, Decoration.

Ссылки, которых не было в исходных материалах, обозначены `null`: нажатие показывает уведомление, не ведёт на выдуманный профиль. Email в подвале сохранён из макета (`hello@example.com`) как временный текст. Перед публикацией замените его и заполните реальные адреса. PDF резюме ещё не предоставлен.

FAQ показывает все ответы сразу, как в актуальном компоненте Figma. Hover — белая подложка. Кнопки и ссылки имеют видимый клавиатурный фокус. Мобильное меню закрывается по Escape и при выборе якоря. На экранах высотой до 740 px и в reduced-motion видеосцена превращается в обычные последовательные блоки с доступным контентом.

## Проверка

`npm test` проверяет обратный скролл, скачки прогресса, крайние значения и замену видео другой длительности. `npm run build` проверяет TypeScript и production-сборку. GitHub Actions запускает оба шага.

Макеты изучены для 1920, 1440, 1200, 1024, 768, 414, 390 и 360 px. Браузерная визуальная проверка в текущей среде не выполнена: preview relay недоступен. Чек-лист для ручной проверки — `docs/verification.md`. Не считать автоматическую сборку подтверждением попиксельного соответствия.

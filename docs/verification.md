# Проверка перед показом или публикацией

## Автоматические проверки

```sh
npm ci
npm test
npm run build
```

Тесты покрывают геометрию Hero на восьми контрольных ширинах, смену брейкпоинтов, обратимость скролл-анимации, пределы времени видео и появление первого кадра. Сборка проверяет TypeScript и генерирует статические файлы сайта.

## Ручная проверка

| Область | Что проверить |
| --- | --- |
| Главная и адаптивы | На ширинах 1920, 1440, 1200, 1024, 768, 414, 390 и 360 px проверьте переносы, интервалы, положение иконок и отсутствие лишнего горизонтального скролла. |
| Hero → About | Прокрутите сцену в обе стороны. Проверьте центрирование портрета, изменение кадров при скролле и доступность текста и действий с включённым reduced motion. |
| Навигация | Откройте якоря Work и Process, кейс, CV и контакты по прямым ссылкам. Проверьте перезагрузку, переходы назад и вперёд и возврат фокуса после закрытия мобильного меню. |
| Кейсы | Проверьте превью, изображения, оглавление и ссылки Explore more projects. Проверьте управление мышью, клавиатурой и касанием. |
| Get in touch | Проверьте обязательные поля, согласие с Privacy Policy, окно подтверждения и закрытие по Escape. |
| Резюме и 404 | Проверьте печать, скачивание PDF и переход с неизвестного адреса на главную. |

Перед живым показом проверьте запуск на компьютере и в браузере, с которых будете вести демонстрацию.

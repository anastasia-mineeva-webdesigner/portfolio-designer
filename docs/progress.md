## Нерешённые вопросы

- Исходная публичная публикация отображает другой состав проектов, чем текущий `main`. Новая тестовая версия синхронизирована с текущим GitHub `main` плюс изменение задачи №1; поэтому она также содержит уже существовавшие в GitHub изменения других блоков.
- Пользователь указал, что актуальная версия была доработана 18 ноября. В публичной публикации найдены VIREON, VEYA и EPOCH, которых нет в GitHub `main` и доступных ветках; последний коммит `main` датирован 17 ноября. Нужен доступ к исходникам этой версии (ветка/репозиторий или экспорт проекта), чтобы не переносить её по собранному JS.
- Отдельный Site «Mira Portfolio — версия для правок» (`appgprj_6afc388b387881918080f6ee9956f08e`) требует входа. Его собственный `project_id` сохранён; публикация другого аккаунта не изменялась.

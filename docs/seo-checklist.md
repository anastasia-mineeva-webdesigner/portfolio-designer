# Сборка, SEO и обновление PDF

## Статическая сборка

Команда `npm run build` собирает приложение в `dist/`. Скрипт [build-seo.mjs](../scripts/build-seo.mjs) создаёт HTML для главной, контактов, резюме, всех кейсов и страницы 404. Адреса и описания кейсов берутся из [cases.json](../src/data/cases.json). Контент страниц отрисовывается React в браузере, а метаданные доступны в исходном HTML.

Каждая страница получает title, description, canonical и метаданные для карточек в соцсетях. Главная содержит JSON-LD с типом ProfilePage. В сборку входят `robots.txt` и `sitemap.xml`. Страница 404 исключена из карты сайта и получает `noindex`.

## Публикация

1. Соберите проект из нужной ревизии.
2. При публикации на другом адресе задайте `SITE_ORIGIN` как полный адрес хоста, например `https://portfolio.example.org`. Он используется в canonical, адресах превью и карте сайта. Маршруты и ресурсы текущей сборки заданы от корня хоста.
3. Опубликуйте содержимое `dist/`. На другом хостинге настройте `404.html` как документ для неизвестных адресов с кодом 404.
4. Проверьте прямое открытие и перезагрузку резюме, контактов и одного из кейсов. Сверьте canonical, карту сайта и доступность изображения из `og:image`.

## Обновление PDF резюме

PDF хранится в [public/downloads/](../public/downloads/) и копируется в сборку. После правок резюме соберите сайт, запустите предпросмотр и откройте отдельный локальный экземпляр Chromium с отладкой на порту 9222. Выполните:

```sh
node scripts/build-cv-pdf.mjs
```

По умолчанию скрипт берёт `http://127.0.0.1:4173/cv/` и подключается к `http://127.0.0.1:9222`. Эти адреса можно указать двумя аргументами. Скрипт обновляет PDF в исходниках и в сборке. Перед публикацией проверьте разбиение на страницы и скачивание через Download CV.

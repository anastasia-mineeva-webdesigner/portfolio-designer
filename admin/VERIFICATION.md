# Проверки отдельной админки

## Изоляция основного сайта

- Проверены все полученные remote-ветки и PR #1–#6; сохранённой реализации админки не найдено. Локальные изменения из предыдущей сессии не были отправлены в GitHub и недоступны в этом окружении.
- База разработки создавалась в отдельном тестовом каталоге; рабочие базы и хостинг не использовались.
- `src/`, `public/`, `index.html`, корневые package/lock, `.openai/hosting.json` не изменены.
- Собраны исходный `origin/main` и рабочая ветка с одинаковыми зависимостями. `diff -qr` каталогов `dist/` не нашёл различий: HTML, JS, CSS, SEO и статические файлы совпадают побайтово.
- Нет CMS-адаптера, публичного API контента или переключателя в публичном приложении. Это намеренно отложено по последнему указанию владельца: не связывать с фронтендом.
- Существующий workflow проверяет сборку и тесты. Новый workflow запускает только тесты `admin/` на Node 24. Ни в одном нет шагов публикации. Внешние настройки сторонних сервисов вне репозитория не менялись. Main и живой сайт не публиковались.

## Автоматические проверки

- `npm test`: 18 существующих тестов прошли.
- `npm run build`: TypeScript, Vite и SEO успешно.
- `npm --prefix admin test`: 5 интеграционных тестов прошли (несколько сценариев в каждом):
  - запрет анонимного чтения черновиков/копий, записи и доступа к загрузкам;
  - точный Origin, CSRF, вход, выход и ограничение неудачных входов;
  - исходное наполнение, сохранение без публикации, конфликт ревизий;
  - отдельное подтверждение публикации, предыдущая версия и откат;
  - сохранность после перезапуска, отсутствие повторного заполнения БД;
  - декодирование/перекодирование изображений, запрет SVG и повреждённых файлов;
  - запрет небезопасных URL, повторных slug, неверной структуры и обхода путей в копиях;
  - перенос резервной копии с файлами в новую независимую базу, сохранение прежней публикации при импорте.
- `npm --prefix admin audit --omit=dev`: 0 уязвимостей после обновления sharp до 0.35.5.
- `git diff --check`: без ошибок.

## Браузер

Chromium через Playwright, desktop 1440×1000 и mobile 390×1000; дополнительно mobile 390×844. Выполнены вход, создание кейса и главы, ввод текста, сохранение, приватный предпросмотр и выход. На мобильном дополнительно: загрузка PNG, редактирование контакта, скачивание JSON-копии, подтверждённая публикация в тестовую CMS, откат, импорт копии с изображением. Сценарии прошли. Нет ошибок JavaScript или горизонтального переполнения. Снимки интерфейса просмотрены.

Главная сайта открыта в обоих размерах. Дополнительная гарантия сохранения внешнего вида — полное совпадение файлов production-сборки с исходной веткой.

## Границы проверки

- Предпросмотр редакционный: подключение к точному шаблону React намеренно не сделано.
- HTTPS, Nginx, systemd, домен, платежи и доступ из российской сети не запускались и не проверялись на реальном сервере. Инструкции и официальные источники оплаты приведены в README.
- JSON-импорт ограничен 64 МБ. Для больших копий и полного восстановления опубликованной/предыдущей версий используется остановленный сервис и копия каталога данных целиком.
- Админка рассчитана на одного владельца и один серверный процесс. Сессии и лимит попыток хранятся в памяти; перезапуск завершает сессии и сбрасывает лимит.
